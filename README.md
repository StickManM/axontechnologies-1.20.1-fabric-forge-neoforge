# Axon T.e.c.h.n.o.l.o.g.i.e.s.
## This is the Repository for the Axon T.e.c.h.n.o.l.o.g.i.e.s. Mod
Axon T.e.c.h.n.o.l.o.g.i.e.s., Also referred as Axon Technologies or axontechnologies adds new ores, armor with their own tool types, status effects, mobs, dimensions, and more. It is currently still being developed, so bugs may occur.

This is a continuation of [A17 1.20.1 Fabric on Modrinth](https://modrinth.com/mod/axontechnologies/version/1.20.1-fabric-A17). This is where it will continue to be updated.

The plan is to convert this project into Architectury and develop both Forge and Fabric.

More information about the mod itself can be found on the [Modrinth page](https://modrinth.com/mod/axontechnologies). This also includes links to an issue tracker, wiki, etc.

To run the mod, download it from Modrinth with its given dependencies: For 1.8 and above, Architectury API and GeckoLib are required (and fabric api for the Fabric version), while for versions A17 and below, only Gecjolib and Fabric API are required. These specific dependencies are listen on the Modrinth page.
